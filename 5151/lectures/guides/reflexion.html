Paper Guide · Week 2 — Reasoning & Planning

Reflexion: Language Agents with Verbal Reinforcement Learning

How an agent gets better across attempts without ever updating a single weight — by writing itself a note about what went wrong and reading it back on the next try.

Read the paper ↗ Shinn, Cassano, Berman, Gopinath, Narasimhan & Yao · NeurIPS 2023 ← Back to Reasoning & Planning
01 · In plain terms

Reinforcement learning, but the “reward signal” is a sentence in English

Classic reinforcement learning improves an agent by adjusting its weights based on a numeric reward. Reflexion keeps the model completely frozen and instead gives it a different kind of memory: after a failed attempt, a second pass over the trace produces a short natural-language reflection — "I made an off-by-one error indexing the array; next time check the boundary condition explicitly" — which is stored and prepended to the prompt on the next attempt. The model's behavior changes not because its parameters moved, but because its input now contains an explicit lesson from its own last failure. This is CoALA's episodic memory, made into the entire mechanism of a whole paper.

02 · How it works

Actor, Evaluator, Self-Reflection — three roles, one loop across trials

Reflexion runs three components in a cycle across multiple episodes (attempts at the same task): the Actor (the policy — usually a ReAct-style agent) acts in the environment; the Evaluator scores the resulting trajectory (a test suite for code, a heuristic or model judge for other tasks); if the score indicates failure, the Self-Reflection component generates a verbal summary of what went wrong, which is written into episodic memory. On the next episode, the Actor's prompt includes the accumulated reflections from all prior failed attempts on this task, and tries again. Crucially, this requires some external feedback signal (did the code pass the tests? did the action succeed?) — Reflexion needs to know it failed before it can reflect on why, which is a real limitation the paper is candid about and the next guide (Huang et al.) probes further.

Reflexion's multi-episode loop — no weights change, only what's in the prompt. Shinn et al., NeurIPS 2023.
Key result On the HumanEval coding benchmark, Reflexion reached 91% pass@1, versus 80% for the GPT-4 baseline it built on — a gain from re-attempts and verbal self-correction alone, no fine-tuning.
Worked exampleTwo episodes on the same coding task
Episode 1Actor writes def is_palindrome(s): return s == s[::-1] EvaluatorTest fails on input "A man, a plan, a canal: Panama" — punctuation and case aren't handled. Self-Reflection"My solution didn't normalize the string first. Next time, strip non-alphanumeric characters and lowercase before comparing." Episode 2Actor (prompt now includes the reflection above) writes a version that filters and lowercases first, then compares. Tests pass.
04 · For your talk & project

What this buys you

  • If you present S1-1 or S1-6 Self-improvement & Reflection: the critical question the "must explain" checklist points at directly applies here — Huang et al. (2024) later showed self-correction without external feedback often fails or hurts accuracy, which is exactly Reflexion's Evaluator dependency. Contrast the two papers explicitly.
  • For your project's evaluation design (R5): if your agent retries or self-corrects, Reflexion is the citation for the mechanism — but be ready to say what your Evaluator's feedback signal actually is, since that's the part that makes or breaks it.
  • A sharp Q&A question for any "self-improving agent" talk: "what happens to this technique on a task with no cheap, reliable pass/fail signal?"
